# TALLAH Header — إصلاح مقاسات الشعار وأيقونة الحساب

|---|---|
| ارتفاع الهيدر (ديسكتوب 1536) | 146px |
| ارتفاع الهيدر (موبايل 390، iframe) | 94px |

| زر الحساب `.s-user-menu-trigger` | **28×28** بلا padding ولا خلفية (`p-0 rounded-sm`) |

| أيقونات البحث/المفضلة/السلة | 20×20 |

## السبب الجذري
1. **الأفاتار:** في الأصل `header.scss` يزيل حشوة مكوّن `<salla-user-menu>` الافتراضية ويجعل الصورة 28px (`.s-user-menu-trigger {p-0 rounded-sm}` و`.s-user-menu-trigger img {h-7 w-7}`). هذه القواعد لم تُنقل إلى `tallah-header.scss`، فبقي الزر بصندوقه الأبيض المحشو وصورته الأكبر (ما ظهر في لقطة المشكلة).
2. **الشعار:** صورة الشعار تأتي من مكوّن `Image` في المحرك بالفئة `object-cover`، فكانت أي نسبة لا تطابق الصندوق تُقصّ/تُمطّ (الأصل `object-contain`). حدود الأبعاد نفسها (`max-h 48`، `max-w 100/170`) مطابقة للأصل، فلم أغيّرها.

## التعديل (ملف واحد، قواعد مضيّقة تحت `.tallah-header`)
`app/styles/04-components/tallah-header.scss`:
- `.tallah-header .tallah-header__logo { object-fit: contain; }`
- `.tallah-header salla-user-menu { shrink-0 }`
- `.tallah-header .s-user-menu-trigger { rounded-sm; خلفية شفافة؛ padding 0؛ min-width/height 0؛ line-height 0 }`
- `.tallah-header .s-user-menu-trigger img / -avatar { 28×28؛ بلا خلفية/حشوة؛ object-fit: cover }`
لم أستخدم أبعاداً عشوائية: 28px هو نفس قياس الأصل (`h-7 w-7`). لم يتغير أي منطق أو مكوّن React (التنقل/البحث/المفضلة/السلة/اللغة كما هي).

## القيود في التحقق (بصراحة)
- **لقطات قبل/بعد:** لم أستطع التقاط لقطة "بعد" للأفاتار الحي: في هذه الجلسة لم يتهيأ SDK سلة (مكوّنات الويب مثل `salla-user-menu` غير معرَّفة رغم تحميل السكربت)، فالمستخدم يظهر غير مسجَّل ولا يُرسم الأفاتار. التحقق تمّ بحقن نفس بنية DOM التي يرسمها المكوّن (`.s-user-menu-trigger > img.s-user-menu-trigger-avatar`) داخل الهيدر الحقيقي مع CSS الحقيقي: النتيجة **28×28، padding 0، خلفية شفافة، radius 2px** — مطابقة للأصل. لقطة "قبل" هي لقطة المشكلة المرسلة.
- حالة غير المسجَّل: الكود يرسم زر أيقونة عادياً (`UserSvg`) لا يتأثر بهذه القواعد (20×20 مثل بقية الأيقونات).
- **NOT VERIFIED:** عروض 375/430/768/1024 وLTR بالقياس الحي بعد التعديل (القواعد لا تعتمد على عرض الشاشة، والأصل بنفس القياس 28px في كل العروض).
