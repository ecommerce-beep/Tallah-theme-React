# TALLAH React — تقرير الاختبار الشامل (Full Theme Regression)

**طريقة العمل:** تدقيق للقراءة فقط (لم يُعدَّل أي كود أو إعداد). متصفح حقيقي على `localhost:5173/dev-vgckq3fssfhjewwi` + فتح المتجر الأصلي `demostore.salla.sa/ar/dev-ff8tnndomnlqddrf` (لم يمنعه Cloudflare) + `curl` على HTML المُصيَّر + اختبارات الوحدة. الاستجابة: iframes بعرض 375/390/430/768/1024/1440 (العرض الفعلي أقل بـ ~15px بسبب شريط التمرير).
**الحالة الأولية:** فرع `main`، آخر commit `fa3ce67`، 23 ملفاً معدّلاً + ملفات جديدة غير متتبَّعة (أعمال Tasks 07–الإصلاحات). `twilight.preview.json` مطابق بايت ببايت للنسخة الأساسية (46 إعداداً + 8 بلوكات).
**سلة المعاينة قبل الاختبار:** كرسي كلاسك (×1) + طاولة سفرة (×1). عدّلتُ كمية الأول مؤقتاً (1→2→1) وأعدتها؛ لم أحذف شيئاً.

## L. الكونسول والتشغيل
- **تحذير SDK:** `Offers is not a string. Returning as-is` (مرتان) من سكربت سلة نفسه — طرف ثالث.
- **أخطاء hydration على PDP:** كلها بسبب خاصية `fdprocessedid` التي تحقنها **إضافة متصفح** (ظهرت في أزرار/حقول عدة)؛ HTML المُصيَّر من الخادم سليم (تحققتُ أن نص التبويبات موجود) — **ليس خللاً في الثيم** (يُعاد التحقق بدون إضافات).
- طلبات فاشلة (≥400) في PDP: **0** من 250. صور مكسورة في الرئيسية: **0**.
- أهداف اللمس: أيقونات الهيدر 20×20 (البحث/المفضلة/السلة) أقل من 24px — **مطابقة لقياس الأصل** (20×20)، تُسجَّل ملاحظة Low.
- **التركيز بلوحة المفاتيح:** الأصل يعرّف مؤشراً عاماً في `reset.scss` (`:focus-visible` بحد primary وفجوة بيضاء)؛ في React **غير موجود** (لا قاعدة `focus-visible` عامة) — ISSUE-01.
