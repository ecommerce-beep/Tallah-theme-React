## C. النوافذ التسويقية
نُفِّذت **الاثنتان** كمكوّن React واحد (`ProductPromoPopups`) بنفس شروط وأنماط الأصل (`product.js` + `app.js`):
- **إشعار التوفر:** فقط للحالتين `out` / `out-and-notify`، والإعداد مفعّل، والرابط صالح (نفس `isUsableSubscriptionUrl`: يرفض الرابط الافتراضي `https://s.salla.sa`، والصفحة الحالية، وغير http/s)، يفتح بعد ثانيتين، يتحقق من البريد، ويرسل `EMAIL` بـ POST بوضع `no-cors` إلى الرابط المضبوط (لا endpoint جديد، ولا تسجيل للبريد)، ثم رسالة نجاح/خطأ بالعربية والإنجليزية ويُغلق.
- **عرض التصنيف:** عند تطابق تصنيف المنتج مع `collection_categories` (يقبل الأشكال الثلاثة للقيمة)، بعد تمرير 600px، مرة واحدة، مع "لا تُذكرني" في `localStorage` (`collection_sp_modal_dont_remind`).
- **الإتاحة:** `role="dialog"` + `aria-modal` + `aria-labelledby/describedby`، حبس التركيز واستعادته (`useDialogFocus`)، إغلاق بـ Esc والنقر على الخلفية وزر الإغلاق.
- **الإعدادات المستهلكة (14):** `newsletter_sp_view_modal`، `newsletter_url_product`، `newsletter_sp_add_image`، `newsletter_sp_block_title`، `newsletter_sp_sub_title`، `collection_sp_view_modal`، `collection_categories`، `collection_add_image`، `collection_sp_block_title`، `collection_sp_sub_title`، `collection_sp_promo_title`، `collectionn_footer_image`، `collection_title`، (+ `popup-options` عنوان قسم فقط). لا إعدادات جديدة ولا تغيير في المفاتيح أو الترتيب أو الافتراضيات.
- **اختبار المتصفح (نافذة التصنيف، إعداد مؤقت ثم استُعيد المعاينة بايت ببايت):** لا تظهر عند 0 و300px، تظهر عند ≥600px بمحتوى الإعدادات، `aria-modal=true`، التركيز داخلها، Esc يغلقها، تفعيل "لا تُذكرني" ثم إغلاق ثم إعادة تحميل ← لا تظهر (والـ localStorage `true`).
- **غير مختبَر في المتصفح:** نافذة التوفر (لا منتج نافد في الكتالوج) — مغطاة بـ 11 اختبار وحدة (التشغيل، الشروط، التحقق من البريد، الإرسال no-cors، العربية/الإنجليزية، الإغلاق).
- **ملاحظة:** في معاينة التطوير المفاتيح غير المحفوظة لا تحمل افتراضيات المانيفست (نصوص النافذة فارغة حتى تُضبط)؛ في المنصة تصل الافتراضيات من الإعدادات.
